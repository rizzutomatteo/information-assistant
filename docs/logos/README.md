# Logos

Official logos of the technologies named in the report, converted from SVG to PDF so that
`pdflatex` can include them. They are used only to identify each technology.

| File | Source |
|---|---|
| docker, fastapi, ollama, oracle, postgresql, pytest | [devicon 2.18.0](https://github.com/devicons/devicon), `*-original.svg` |
| caddy, chatwoot, opensearch | [simple-icons 16.36.0](https://github.com/simple-icons/simple-icons), coloured with the brand colour listed there |
| gemini, groq, langgraph, mcp, openai, qwen | [lobe-icons 1.101.0](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg`); Groq in its brand orange |
| keycloak | [CNCF artwork](https://github.com/cncf/artwork), `projects/keycloak/icon/color` |
| docling | [docling-project/docling](https://github.com/docling-project/docling), `docs/assets/logo.svg` |
| presidio | [microsoft/presidio](https://github.com/microsoft/presidio), `docs/api-docs/logo.svg` |
| promptfoo | [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo), `plugins/promptfoo/assets/promptfoo-panda.svg` |
| ragas | [explodinggradients/ragas](https://github.com/explodinggradients/ragas), `docs/_static/imgs/logo-black.svg` |
| valkey | [valkey-io/assets](https://github.com/valkey-io/assets), `slides/icons/valkey-mark-color.svg` |

gpt-oss is shown with the OpenAI logo, which released it. EasyOCR has no official logo, so the
figures show it next to the Docling logo. Components that are not third-party products (the web
chat, the core insurance system, the validator, the audit) use generic icons from Font Awesome.
